# Job Application Tracker

A clean, modern, and mature Job Application Tracker built with vanilla HTML, CSS, and JavaScript.

## Features

- **Add & Edit Applications**: Track Company, Role, and Status (`Applied`, `Interviewing`, `Offer`, `Rejected`).
- **Interactive Metrics**: Live counts and clickable filter tabs for total applications and each status pipeline.
- **Real-Time Search & Filtering**: Instant search across companies, roles, and statuses with `<kbd>/</kbd>` shortcut.
- **Delete Confirmation**: Protected deletion with preview modal to prevent accidental data loss.
- **Local & Private**: All data is stored in the browser's `localStorage`—no servers, databases, or tracking.
- **Responsive Design**: Tailored for both phone screens and desktop displays.
- **Zero Dependencies**: Pure HTML5, CSS3, and modern vanilla JavaScript.

## Getting Started

Simply open `index.html` in any modern web browser or run:

```bash
open index.html
```
